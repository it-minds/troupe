# The minisign public keys a release is signed with (#66, Decision 865), one base64 line
# (`RW...`) each. Every troupe and troupe-daemon is built with these and installs only a
# release whose manifest one of them signed; nothing at run time adds one.
#
# The first is the current key: CI signs with it (the `release` environment's secret
# RELEASE_MINISIGN_KEY), and `scripts/release-installers` writes it into the installers
# attached to a release. A key being rotated out stays below it for one release, signed
# with RELEASE_MINISIGN_KEY_PREVIOUS as well, so that a client built before the rotation
# can still check that release.
#
# None yet: until the maintainer creates the key and adds its public half here, a build
# trusts no key, `troupe update` installs nothing, and the release workflow refuses to
# publish (docs/developer/ci.md, "The release key").
